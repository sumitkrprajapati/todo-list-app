📝 To-Do List App

A simple and responsive To-Do List web application built using HTML, CSS, and JavaScript. It helps users organize their daily tasks and track their progress easily.

🚀 Live Demo

"Click here to use the To-Do List App" (https://sumitkrprajapati.github.io/todo-list-app/)

✨ Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 💾 Save tasks using Local Storage
- 🔄 Tasks remain saved after refreshing the page
- 📱 Responsive user interface
- ⌨️ Add tasks by pressing Enter

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

💻 How to Run Locally

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open "index.html" using Live Server, or open it in your browser.
